# Board images

Upload the images for the quiz board into this folder with these names.
The ending can be .jpg, .jpeg, .png or .webp. Names are case-sensitive.

| Question | Zoomed / question image | Full / answer image |
|---|---|---|
| Logo, easy | `logo-easy-zoom` | `logo-easy-full` |
| Logo, medium | `logo-medium-zoom` | `logo-medium-full` |
| Logo, hard | `logo-hard-zoom` | `logo-hard-full` |
| Child, easy | `child-easy` | (parents' names go in `board-config.js`) |
| Child, medium | `child-medium` | |
| Child, hard | `child-hard` | |

To swap an image, upload a new file with the same name. If you upload a
different ending than before (say .png instead of .jpg), delete the old
file, otherwise the page keeps showing the old one.
